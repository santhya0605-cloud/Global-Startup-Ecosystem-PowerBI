# Global Startup Ecosystem & Unicorn Analytics Dashboard

 Project Overview

The **Global Startup Ecosystem & Unicorn Analytics Dashboard** is an interactive Power BI project developed to analyze and visualize trends in the global startup and unicorn ecosystem.

The project combines data from **three startup and unicorn datasets** to create a consolidated analytical view covering startup funding, valuations, industries, investors, and geographical distribution.

The data was cleaned, transformed, and prepared for analysis before being integrated into an interactive Power BI dashboard.

---

 Project Objectives

* Analyze the global distribution of startup and unicorn companies.
* Explore startup funding and valuation patterns.
* Compare startup activity across countries and industries.
* Analyze investor participation within the startup ecosystem.
* Identify patterns and trends across the combined datasets.
* Develop an interactive dashboard for data exploration and business analysis.

 Datasets

This project combines information from three publicly available Kaggle datasets:

### 1. Global Startup Funding & Valuation Dataset

Contains information related to global startup funding and valuations.

**Source:** [Kaggle – Global Startup Funding & Valuation Dataset](https://www.kaggle.com/datasets/pranshuljoshi/global-startup-funding-and-valuationcleaned-dataset)

### 2. Unicorn Companies Dataset

Contains information about unicorn companies and their characteristics.

**Source:** [Kaggle – Unicorn Companies Dataset](https://www.kaggle.com/datasets/deepcontractor/unicorn-companiesdataset)

### 3. Global Unicorn Startups Dataset

Contains additional information related to global unicorn startups.

**Source:** [Kaggle – Global Unicorn Startups Dataset](https://www.kaggle.com/datasets/mafaqbhatti/global-unicorn-startups2026)

### Data Integration

The three datasets were combined and prepared to create a broader analytical view of the global startup ecosystem.

The integration process involved reviewing the available fields, cleaning the data, transforming columns, and preparing the combined data for Power BI analysis.

---

Data Preparation & Transformation

Data preparation was performed using **Power Query and Power BI**.

The main steps included:

* Reviewing the structure of the three datasets
* Combining data from multiple sources
* Cleaning inconsistent or missing values
* Transforming columns and data types
* Removing unnecessary data
* Standardizing fields where required
* Preparing the combined dataset for visualization and analysis
